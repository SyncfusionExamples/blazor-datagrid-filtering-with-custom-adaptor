# Blazor DataGrid - Filtering with Custom Adaptor

## Overview

This sample demonstrates how to perform filtering operations in the Syncfusion Blazor DataGrid while using a custom data adaptor. Instead of binding directly to a standard data source, the DataGrid uses an `SfDataManager` configured with a custom adaptor implementation that extends the `DataAdaptor` class. The sample shows how filtering requests generated by the DataGrid can be processed manually inside the adaptor by overriding the `Read` method and executing filtering logic using Syncfusion data operations. Paging is also handled within the adaptor, making this sample a useful reference for developers who need custom data-processing logic while retaining built-in DataGrid features.

## Key Features

- Uses the Syncfusion `SfGrid` component with `AllowFiltering="true"` and `AllowPaging="true"`.
- Configures data binding through `SfDataManager`.
- Uses `Adaptor="Adaptors.CustomAdaptor"` together with `AdaptorInstance="@typeof(CustomAdaptor)"`.
- Implements a custom adaptor by extending the `DataAdaptor` class.
- Overrides the `Read(DataManagerRequest dm, string key = null)` method to process DataGrid requests.
- Performs filtering using `DataOperations.PerformFiltering(DataSource, dm.Where, dm.Where[0].Operator)`.
- Supports paging through `DataOperations.PerformSkip` and `DataOperations.PerformTake`.
- Generates sample data using an in-memory `Order` collection.
- Demonstrates custom data processing while maintaining standard DataGrid filtering and paging features.
- Includes columns for `OrderID`, `CustomerID`, and `Freight` with DataGrid configuration defined directly in the Razor page.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download the repository.
2. Open the solution file `FilteringWithCustomAdaptor.sln`.
3. Restore all NuGet packages.
4. Set the `FilteringWithCustomAdaptor` project as the startup project if required.
5. Build the solution.
6. Run the project using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the project directory.

```bash
cd FilteringWithCustomAdaptor/FilteringWithCustomAdaptor
dotnet restore
dotnet run
```

4. Open the local URL displayed in the terminal after the application starts.

## Project Structure

- `FilteringWithCustomAdaptor/FilteringWithCustomAdaptor/Pages/Index.razor` — contains the `SfGrid` implementation, `SfDataManager` configuration, `Order` model, sample data generation, and the `CustomAdaptor` implementation.
- `FilteringWithCustomAdaptor/FilteringWithCustomAdaptor/Data/` — contains supporting data-related files used by the Blazor application.
